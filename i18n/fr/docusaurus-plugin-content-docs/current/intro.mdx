# Introduction au tutoriel

Découvrez **Docusaurus en moins de 5 minutes**.

## Pour commencer

Commencez par **créer un nouveau site**.

Ou **essayez Docusaurus immédiatement** via **[docusaurus.new](https://docusaurus.new)**.

### Ce dont vous avez besoin

- [Node.js](https://nodejs.org/en/download/) version 20.0 ou supérieure :
  - Lors de l’installation de Node.js, il est recommandé de cocher toutes les cases relatives aux dépendances.

## Générer un nouveau site

Générez un site Docusaurus à l’aide du **modèle classique**.

Le modèle classique sera automatiquement ajouté à votre projet après exécution de la commande :

```bash
npm init docusaurus@latest my-website classic
```

Vous pouvez saisir cette commande dans l’Invite de commandes, PowerShell, Terminal ou tout autre terminal intégré de votre éditeur de code.
Cette commande installe également toutes les dépendances nécessaires pour exécuter Docusaurus.

## Lancer votre site

Démarrez le serveur de développement :

```bash
cd my-website
npm run start
```

La commande `cd` permet de changer le répertoire de travail. Pour accéder à votre nouveau site Docusaurus, vous devez vous y rendre dans le terminal.

La commande `npm run start` construit le site localement et le diffuse via un serveur de développement, accessible à l’adresse http://localhost:3000/.

Ouvrez le fichier `docs/intro.md` (cette page) et modifiez quelques lignes : le site **se recharge automatiquement** et affiche vos modifications.
