# Déployer votre site

Docusaurus est un **générateur de site statique** (également appelé **[Jamstack](https://jamstack.org/)**).

Il génère votre site sous forme de simples **fichiers statiques HTML, JavaScript et CSS**.

## Générer votre site

Construisez votre site **pour la production** :

```bash
npm run build
```

Les fichiers statiques sont générés dans le dossier `build`.

## Déployer votre site

Testez votre build de production en local :

```bash
npm run serve
```

Le dossier `build` est alors servi à l'adresse [http://localhost:3000/](http://localhost:3000/).

Vous pouvez désormais déployer le dossier `build` **presque partout** facilement, **gratuitement** ou pour un coût très faible (lisez le **[Guide de déploiement](https://docusaurus.io/docs/deployment)**).
