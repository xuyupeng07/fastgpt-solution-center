# Fonctionnalités Markdown

Docusaurus prend en charge **[Markdown](https://daringfireball.net/projects/markdown/syntax)** et quelques **fonctionnalités supplémentaires**.

## Front Matter

Les documents Markdown possèdent des métadonnées en en-tête appelées [Front Matter](https://jekyllrb.com/docs/front-matter/) :

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: My document title
description: My document description
slug: /my-custom-url
---
// highlight-end

Markdown content
```

## En-têtes {/* #my-heading-id */}

Les en-têtes Markdown sont pris en charge à l'aide de la syntaxe standard « # » et sont automatiquement ajoutés à la table des matières. Le nombre de `#` correspond au niveau de l'en-tête.

```md
## Headings

My text
```

### Identifiants d'en-tête {/* #my-custom-id */}

Ajoutez `{/* #my-custom-id */}` après le texte de l'en-tête pour lui assigner un identifiant d'ancre explicite, utilisé pour les liens.

```md
### Heading Ids {/_ #my-custom-id _/}
```

## Liens

Les liens Markdown classiques sont pris en charge, en utilisant des chemins d'URL ou des chemins de fichiers relatifs.

```md
Let's see how to [Create a page](/create-a-page).
```

```md
Let's see how to [Create a page](./create-a-page.mdx).
```

**Résultat :** voyons comment [créer une page](./create-a-page.mdx).

## Images

Les images Markdown classiques sont prises en charge.

Vous pouvez utiliser des chemins absolus pour référencer les images du répertoire statique (`static/img/docusaurus.png`) :

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

Vous pouvez également référencer des images de manière relative au fichier courant. C'est particulièrement utile pour placer les images à proximité des fichiers Markdown qui les utilisent :

```md
![Docusaurus logo](./img/docusaurus.png)
```

## Blocs de code

Les blocs de code Markdown sont pris en charge avec une coloration syntaxique.

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```
````

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```

## Admonitions

Docusaurus dispose d'une syntaxe spéciale pour créer des encadrés (admonitions) et des mises en avant :

```md
:::tip[My tip]

Use this awesome feature option

:::

:::danger[Take care]

This action is dangerous

:::
```

:::tip[Mon astuce]

Utilisez cette formidable option de fonctionnalité

:::

:::danger[Attention]

Cette action est dangereuse

:::

## MDX et composants React

[MDX](https://mdxjs.com/) peut rendre votre documentation plus **interactive** et permet d'utiliser **n'importe quel composant React dans Markdown** :

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`You clicked the color ${color} with label ${children}`)
    }}>
    {children}
  </span>
);

This is <Highlight color="#25c2a0">Docusaurus green</Highlight> !

This is <Highlight color="#1877F2">Facebook blue</Highlight> !
```
