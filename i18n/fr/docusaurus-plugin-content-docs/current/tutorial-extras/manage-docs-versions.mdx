# Gérer les versions des documents

Docusaurus peut gérer plusieurs versions de votre documentation.

## Créer une version de documentation

Publiez une version 1.0 de votre projet :

```bash
npm run docusaurus docs:version 1.0
```

Le dossier `docs` est copié dans `versioned_docs/version-1.0` et le fichier `versions.json` est créé.

Votre documentation dispose désormais de 2 versions :

- `1.0` à `http://localhost:3000/docs/` pour les documents de la version 1.0
- `current` à `http://localhost:3000/docs/next/` pour les **documents à venir, non encore publiés**

## Ajouter une liste déroulante de versions

Pour naviguer facilement entre les versions, ajoutez une liste déroulante de versions.

Modifiez le fichier `docusaurus.config.js` :

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'docsVersionDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

La liste déroulante de versions apparaît dans votre barre de navigation :

![Liste déroulante des versions de documentation](./img/docsVersionDropdown.png)

## Mettre à jour une version existante

Il est possible de modifier les documents versionnés dans leur dossier respectif :

- `versioned_docs/version-1.0/hello.md` met à jour `http://localhost:3000/docs/hello`
- `docs/hello.md` met à jour `http://localhost:3000/docs/next/hello`
