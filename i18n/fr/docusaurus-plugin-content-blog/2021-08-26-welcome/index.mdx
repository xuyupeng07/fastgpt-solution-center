Les [fonctionnalités de blog de Docusaurus](https://docusaurus.io/docs/blog) sont propulsées par le [plugin blog](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-blog).

Voici quelques astuces qui pourraient vous être utiles.

{/* truncate */}

Ajoutez simplement des fichiers Markdown (ou des dossiers) dans le répertoire `blog`.

Les auteurs réguliers de blog peuvent être ajoutés dans `authors.yml`.

La date d'un article de blog peut être extraite des noms de fichiers, par exemple :

- `2019-05-30-welcome.md`
- `2019-05-30-welcome/index.md`

Un dossier d'article peut s'avérer pratique pour regrouper les images de l'article :

![Docusaurus Plushie](./docusaurus-plushie-banner.jpeg)

Le blog prend également en charge les balises !

**Et si vous ne voulez pas de blog** : supprimez simplement ce répertoire et utilisez `blog: false` dans la configuration de Docusaurus.
