# 翻译你的站点

让我们将 `docs/intro.md` 翻译成法语。

## 配置国际化 (i18n)

修改 `docusaurus.config.js` 以支持 `fr` 语言:

```js title="docusaurus.config.js"
export default {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'fr'],
  },
};
```

## 翻译一个文档

将 `docs/intro.md` 文件复制到 `i18n/fr` 目录:

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

用法语翻译 `i18n/fr/docusaurus-plugin-content-docs/current/intro.md`。

## 启动你的本地化站点

以法语语言启动你的站点:

```bash
npm run start -- --locale fr
```

你的本地化站点可在 [http://localhost:3000/fr/](http://localhost:3000/fr/) 访问,并且 `Getting Started` 页面已被翻译。

:::caution

在开发模式下,你一次只能使用一种语言。

:::

## 添加语言下拉菜单

为了在各语言之间顺畅切换,请添加一个语言下拉菜单。

修改 `docusaurus.config.js` 文件:

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'localeDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

语言下拉菜单现在会出现在你的导航栏中:

![语言下拉菜单](./img/localeDropdown.png)

## 构建你的本地化站点

为特定语言构建你的站点:

```bash
npm run build -- --locale fr
```

或者一次性构建包含所有语言的站点:

```bash
npm run build
```
