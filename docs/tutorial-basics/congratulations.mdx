# 恭喜!

你已经学会了 **Docusaurus 的基础知识**,并对 **初始模板** 做了一些修改。

Docusaurus 还有 **更多内容等着你**!

还有 **5 分钟**?看看 **[版本管理](../tutorial-extras/manage-docs-versions.mdx)** 和 **[国际化 (i18n)](../tutorial-extras/translate-your-site.mdx)**。

本教程中有什么 **不清楚** 或 **有 bug** 的地方?[请反馈给我们!](https://github.com/facebook/docusaurus/discussions/4610)

## 下一步做什么?

- 阅读 [官方文档](https://docusaurus.io/)
- 通过 [`docusaurus.config.js`](https://docusaurus.io/docs/api/docusaurus-config) 修改你的站点配置
- 通过 [`themeConfig`](https://docusaurus.io/docs/api/themes/configuration) 添加导航栏和页脚项目
- 添加自定义的 [设计与布局](https://docusaurus.io/docs/styling-layout)
- 添加 [搜索栏](https://docusaurus.io/docs/search)
- 在 [Docusaurus 案例展示](https://docusaurus.io/showcase) 中寻找灵感
- 参与 [Docusaurus 社区](https://docusaurus.io/community/support)
