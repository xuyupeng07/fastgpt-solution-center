# Markdown 功能

Docusaurus 支持 **[Markdown](https://daringfireball.net/projects/markdown/syntax)**,并提供一些 **附加功能**。

## Front Matter

Markdown 文档顶部有一段称为 [Front Matter](https://jekyllrb.com/docs/front-matter/) 的元数据:

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: My document title
description: My document description
slug: /my-custom-url
---
// highlight-end

Markdown content
```

## 标题 {/* #my-heading-id */}

Markdown 标题使用标准的 "#" 语法,并会自动添加到目录中。"#" 的数量对应标题的层级。

```md
## Headings

My text
```

### 标题 ID {/* #my-custom-id */}

在标题文本后添加 `{/* #my-custom-id */}`,可以为标题指定用于链接的锚点 ID。

```md
### Heading Ids {/_ #my-custom-id _/}
```

## 链接

支持使用 URL 路径或相对文件路径的标准 Markdown 链接。

```md
Let's see how to [Create a page](/create-a-page).
```

```md
Let's see how to [Create a page](./create-a-page.mdx).
```

**结果:** 让我们看看如何 [创建页面](./create-a-page.mdx)。

## 图片

支持标准的 Markdown 图片。

你可以使用绝对路径来引用静态目录(`static/img/docusaurus.png`)中的图片:

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

你也可以引用相对于当前文件的图片。这尤其适合把图片放在使用它们的 Markdown 文件附近:

```md
![Docusaurus logo](./img/docusaurus.png)
```

## 代码块

Markdown 代码块支持语法高亮。

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```
````

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```

## 提示框 (Admonitions)

Docusaurus 提供了一种特殊语法来创建提示框和标注:

```md
:::tip[My tip]

Use this awesome feature option

:::

:::danger[Take care]

This action is dangerous

:::
```

:::tip[我的提示]

使用这个很棒的功能选项

:::

:::danger[请注意]

此操作具有危险性

:::

## MDX 与 React 组件

[MDX](https://mdxjs.com/) 能让你的文档更具 **交互性**,并允许在 **Markdown 内部使用任意 React 组件**:

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`You clicked the color ${color} with label ${children}`)
    }}>
    {children}
  </span>
);

This is <Highlight color="#25c2a0">Docusaurus green</Highlight> !

This is <Highlight color="#1877F2">Facebook blue</Highlight> !
```
