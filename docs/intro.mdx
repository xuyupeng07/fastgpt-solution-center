# 教程简介

用不到 5 分钟了解 **Docusaurus**。

## 快速开始

从 **创建一个新站点** 开始。

或者通过 **[docusaurus.new](https://docusaurus.new)** **立即体验 Docusaurus**。

### 环境要求

- [Node.js](https://nodejs.org/en/download/) 版本 20.0 或以上:
  - 安装 Node.js 时,建议勾选所有与依赖相关的选项。

## 生成一个新站点

使用 **classic 模板** 生成一个新的 Docusaurus 站点。

当你运行以下命令后,classic 模板会自动添加到你的项目中:

```bash
npm init docusaurus@latest my-website classic
```

你可以在命令提示符、Powershell、终端或代码编辑器自带的任何集成终端中输入此命令。

该命令还会安装运行 Docusaurus 所需的全部依赖。

## 启动你的站点

运行开发服务器:

```bash
cd my-website
npm run start
```

`cd` 命令用来切换工作目录。为了操作你新建的 Docusaurus 站点,你需要在终端中进入该目录。

`npm run start` 命令会在本地构建你的网站,并通过开发服务器提供服务,你可以在 http://localhost:3000/ 查看。

打开 `docs/intro.md`(即本页面)并修改几行内容:**网站会自动刷新** 并显示你的更改。
